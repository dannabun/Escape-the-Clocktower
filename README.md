# Escape the Clocktower

## Group Members

- Danna Bundogji
- Anwar Bakhos

## Game Description

Escape the Clocktower is a 3D escape room game created in Unity. The player explores several rooms, solves simple puzzles, collects objects, avoids moving obstacles, and finds the final exit.

## Current Project Target

Our current target is to create a playable prototype containing:

- A starting room
- A second puzzle room
- A final escape room
- Basic player movement
- At least one working puzzle
- A door that opens after solving the puzzle
- Basic lighting
- A simple menu

## Final Project Goals

For the final version, we plan to include:

- Three connected rooms
- Multiple puzzles
- A moving obstacle or enemy
- Door and object animations
- Camera movement
- Multiple types of lighting
- Main menu and pause menu
- Win or escape screen
- A short gameplay video
